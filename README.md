# Paperweight 🗿

> Русская версия — форк [wslyvh/paperweight](https://github.com/wslyvh/paperweight). Переведён интерфейс приложения; шаблоны GDPR-писем компаниям остаются на языке получателя (английский, немецкий, французский и т. д.).

**Ваша почта знает, где хранятся ваши данные. Мы помогаем вернуть контроль.**

<img src="website/public/dashboard.png" alt="Обзор" width="600" />

Каждый созданный аккаунт, каждый сервис, на который вы подписались, каждая онлайн-покупка привязаны к вашему email. У большинства людей больше 100 забытых аккаунтов — это риск для безопасности и приватности.

Paperweight сканирует почту, составляет карту вашего цифрового следа и помогает удалить данные.

Всё локально. Данные остаются на вашем компьютере.

## Возможности

- **Массовая отписка** — найти и отписаться от рекламных и массовых рассылок за минуты
- **Список аккаунтов** — какие компании и сервисы хранят ваши данные
- **Утечки** — узнать, если компания, которой вы пользуетесь, пострадала от утечки (через haveibeenpwned.com)
- **Запросы на удаление по GDPR** — сформировать запрос на удаление данных
- **Локальная работа** — письма и настройки остаются на вашем устройстве
- **Приватность** — никакие данные не отправляются на внешние серверы
- **Открытая разработка** — исходный код доступен для проверки

## Быстрый старт

1. Скачайте [последний выпуск](https://github.com/wslyvh/paperweight/releases) для вашей платформы (это английская версия автора; русскую нужно собрать из этого форка — см. «Разработка»)
2. Подключите почту
3. Просканируйте ящик (~2 минуты)
4. Изучите свой цифровой след; в Pro можно отписываться и удалять письма

## Лицензия

Находить, изучать и разбирать цифровой след можно бесплатно. Pro открывает действия по очистке и поддерживает разработку.

- **Бесплатно**: один почтовый аккаунт, синхронизация всей истории, поиск аккаунтов и рассылок, обзор утечек и личных данных, локальная разметка
- **Cleanup Pass**: полный доступ Pro на 30 дней для разовой чистки. Один платёж, без продления. Поддержка через сообщество на GitHub.
- **Paperweight Pro**: поддержание приватности весь год, с поддержкой по email.

Оба платных тарифа открывают отписку, удаление, отметку спама, массовую очистку, запросы о персональных данных и повторные запросы, несколько почтовых аккаунтов и доступ по MCP. Оплата картой или вручную криптовалютой.

[Тарифы и цены →](https://www.paperweight.email/pricing)

## Разработка

Официальные сборки поставляются с настроенными OAuth-ключами. Для сборки из исходников нужны свои.

```bash
yarn
cp .env.example .env   # затем заполните три ID ниже
yarn dev
```

Значения OAuth вшиваются при сборке (`electron.vite.config.ts`). Пустые значения в `.env` превращаются в пустые строки, и авторизация падает во время работы.

**Google / Gmail** — https://console.cloud.google.com/
- Создайте учётные данные OAuth 2.0, тип приложения «Desktop app»
- Включите Gmail API
- Добавьте scope `https://www.googleapis.com/auth/gmail.modify` на экране согласия
- Пока приложение в тестовом режиме, добавьте себя в тестовые пользователи
- Пропишите `GOOGLE_CLIENT_ID` и `GOOGLE_CLIENT_SECRET` в `.env`

**Microsoft** — https://portal.azure.com/
- Зарегистрируйте приложение, типы аккаунтов «Personal + work/school»
- Authentication → добавьте «Mobile and desktop applications» с redirect URI `http://localhost`
- API permissions → Microsoft Graph → Delegated → `User.Read`, `Mail.ReadWrite`, `Mail.Send`, `offline_access`, `openid`, `profile`
- Пропишите `MICROSOFT_CLIENT_ID` в `.env` (секрет не нужен, используется PKCE)

Для IMAP-аккаунтов переменные OAuth не нужны.

## Участие

Отзывы, сообщения об ошибках и PR приветствуются.

**Языковые словари** — движок анализа Paperweight классифицирует письма
(покупки, уведомления, реклама) и находит ссылки отписки по словарям фраз
для каждого языка. Английский и нидерландский выверены, остальным языкам
нужны носители. Русского словаря пока нет. Добавить или улучшить язык — это
один файл с данными, знание движка не требуется. Правила:
[`analysis/src/data/lexicons/README.md`](analysis/src/data/lexicons/README.md).
